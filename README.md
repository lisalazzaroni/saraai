# SaraAI

Una piccola homepage chat-first ispirata all'impostazione essenziale della homepage di OpenAI, con identità e contenuti originali per SaraAI.

## Avviare in locale

Serve Python 3. Apri PowerShell in questa cartella ed esegui:

```powershell
py -m http.server 4173
```

Poi apri <http://localhost:4173> nel browser. Per fermare il server, premi `Ctrl+C` nella finestra PowerShell.

Il sito non richiede installazione di pacchetti né un account. La chat è un prototipo interattivo con risposte dimostrative eseguite nel browser; non usa un modello AI o invia dati a un servizio esterno. Le conversazioni create vengono salvate nel browser e si riaprono dalla barra laterale su una pagina dedicata. Puoi eliminare una chat dal relativo pulsante cestino nella barra laterale.
